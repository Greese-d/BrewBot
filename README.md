# BrewBot

Name: 
BrewBot

Description: 
The new robot arm we will design will be similar to the Dobot Nova 2. Its primary function will be to make espresso. We chose this model due to its compact size and ideal reach length of 625 mm, which is perfect for the coffee-making process. Additionally, the robot's 2 kg payload capacity is sufficient for handling a cup of coffee, ensuring precise and efficient operation. Its size and capabilities make it well-suited for small spaces, such as kitchens or cafés, where efficient, automated coffee preparation can enhance workflow and service speed.
